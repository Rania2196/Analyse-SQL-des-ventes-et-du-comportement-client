# Analyse-SQL-des-ventes-et-du-comportement-client
Projet d’analyse SQL consacré aux ventes et au comportement client. Il comprend 18 requêtes permettant d’étudier les performances commerciales, la fidélité, les produits, les canaux de vente et les tendances temporelles à l’aide de filtres, jointures, agrégations, GROUP BY, HAVING et CASE WHEN.
